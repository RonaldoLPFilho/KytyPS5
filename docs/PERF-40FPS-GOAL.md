## 阶段：渲染线程一分为二（40 FPS）

完成判据同上（PGO+LTO、官方场景同进程 A/B ≥ 4 轮 × 10 秒、平均 ≥ 40.0 FPS），另加：拆分模式可运行时开关（同进程 A/B）；
拆分校验模式（前端预计算、后端重算比较）0 不一致；10 分钟游玩稳定。

设计方向（待 S0 数据确认）：前端线程（现 GPU 线程）负责调度（队列轮转、WAIT_REG_MEM）、PM4 解析、寄存器状态和可提前的纯 CPU 工作
（程序查找、SRT 求值、原生 XPR 读字比对）；后端线程只执行（缓存、同步/上传、绑定、录制、客体命令）。前端读到"后端尚未执行的写"
（排队项的缓冲/目标写入、DMA/WRITE_DATA/EOP 目标）或 GPU 所有页时，该项交后端按原路径求值。

- [ ] **S0 可行性数据**：前端可承担的时间（程序/SRT/原生读字/PM4）、WAIT_REG_MEM 与挂起次数、SRT 读到 GPU 页的频率、
      副作用包（DMA/WRITE_DATA/EOP/间接）次数、客体命令（SendCommandSync）次数。
- [ ] **S1 管线骨架**：单生产者单消费者队列、后端线程、排空/屏障、运行时开关、客体命令改由后端执行；先让前端只做解析+调度（结果不变）。
- [ ] **S2 前端预计算**：dispatch/draw 的程序与 SRT 求值、原生 XPR 读字比对移到前端；待写集合；校验模式。
- [ ] **S3 负载平衡与开销**：量两线程忙时，移动边界，降低队列开销。
- [ ] **S4 验收**。
